# DragonUI-Arden

面向 Arden（飞升）客户端的 DragonUI 整合版，基于 DragonUI CoA 4.1.1。

## 安装

退出游戏，备份现有的 `DragonUI` 和 `DragonUI_Options` 插件目录，再把本包同名的两个文件夹放进 `Interface/AddOns/`。建议一并备份 WTF 下的 `DragonUI.lua` 配置文件。两版使用同一个 `DragonUIDB`，本包会读取已有配置。进入游戏后用 `/dui` 打开设置。

## 整合内容

- 保留 CoA 4.1.1 的世界地图、法术书、专业技能、个人资源条和 WoW Forever 界面。天赋继续由游戏客户端提供。
- 加入飞升自动交接任务、错误提示过滤、删除确认自动填充、定制团队框体、BetterBlizzFrames 框体增强和攻击计时条。启用攻击计时条时由它接管平砍计时，包含敌方目标计时。
- 接入 NPC 名翻译、姓名板目标放大、显示距离和仅名称模式的受伤血条，以及聊天表情、时间戳、帧率延迟显示、背包反向整理、光环排序和自定义姿态按钮。
- 使用飞升的简中字体和框体位置保护。上游签名版本广播在整合版中停用。

## 验证范围

已检查 Lua 5.1 语法、插件清单和天赋模块的加载状态。飞升客户端内的登录、战斗和团队场景仍需实测。
